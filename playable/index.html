SNS のフィードで遊べる広告（プレイアブル広告）

記事に貼る iframe 版と同じゲームを、TikTok や Meta の縦型フィードの中で その場で遊べる形にしたものです。下の端末の中で実際にプレイできます。

1掲載イメージ

フィードの見た目は特定サービスの UI を再現したものではなく、縦型フィード一般のイメージです。 ストアへの遷移は起きません（何が呼ばれたかをログに出します）。

なぜ配信先を選ぶ必要があるのか プレイアブル広告は、ストアへ送る手段がネットワークごとに違います。 ここでは各社の SDK を広告枠の中に模擬的に用意し、同じ1ファイルが配信先を見分けて 正しい API を呼び分けることを確認できるようにしています。ゲーム側に配信先の判定は書いていません。

4先に確認が必要なこと

この枠は「アプリ広告」の枠です TikTok のプレイアブル広告は App Promotion 目的（アプリインストール等）に限定されており、 Meta も同様にアプリ広告の枠です。ストアに実在するアプリが必要なため、 Web の LP へ誘導する案件ではこの枠を使えない可能性があります。 広告主の目的がインストール獲得か Web 誘導かによって、この形式が使えるかどうかが変わります。
  • 入稿前に、Meta の Playable Preview Tool（開発者向け・無料）で仕様と CTA 実装を検証します。
  • TikTok の window.openAppStore() は外部 SDK 経由と案内されている一方、同社は外部リクエストを禁止しています。 コンテナ側が注入する前提として script タグは埋め込んでいません。入稿時に要確認です。
  • 現在は開始画面を1枚挟む構成です。接触時間の短い枠では不利な可能性があるため、 即プレイ開始版との比較を検討しています。
  • 実機（iOS / Android）での縦向き表示・タッチ・音は未確認です。
