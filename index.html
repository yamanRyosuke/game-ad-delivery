ゲームを広告として掲載する

同じゲームを、掲載先に合わせて3つの形式で用意しています。 画像・スクリプト・音はすべて当方で用意するため、御社側での開発・ファイル設置は不要です。 下のタブで形式を切り替えてください。どの形式もその場で遊べます。

1ゲームを選ぶ

どれも表示は正方形（1:1）で統一してあります。 ゲームを差し替えても、貼るコードの形と枠の大きさは変わりません。

「埋め込みコード」ボタンについて 上のプレビューの右下に出ているボタンからも、同じコードをコピーできます。 このボタンはこのメニューと、ゲームを直接開いたときにだけ表示されます。 実際に記事へ埋め込むと自動的に隠れるので、読者には見えません。

2貼り方

コピーしたコードを、記事本文の掲載したい位置に貼り付けてください。形は次のとおりです （src のゲーム名の部分だけが入れ替わります）。 

読み込み中…

3共通仕様

表示サイズ正方形（1:1）。原寸 720×720px、最大幅 720px で縮小表示。全ゲーム共通
実装HTML / CSS / JavaScript（Canvas 2D）。外部ライブラリ・フレームワークなし
操作タップ / クリック。キーボード（Space・Enter）にも対応
音あり。ページを開いただけでは鳴りません（「はじめる」押下後のみ）
Cookie / 個人情報いずれも使用・取得していません
計測表示・接触・完了・CTA クリックを postMessage で親ページへ送信（受け取りは任意）
CTAゲーム終了後に「詳しくはこちら」を表示。新しいタブで開くため、記事のページは残ります

SNS のフィードの中で、そのまま遊べる形式

TikTok や Meta の縦型フィードに流れてくる広告の中で、その場で遊べます。 記事に貼る iframe 版と違い、単体 HTML 1枚に画像・スクリプトまで内包し、 外部への通信を一切行いません（各社の審査要件のため）。

掲載先TikTok / Meta の縦型フィード（アプリの中）
目的の制限アプリ広告の枠。ストアに実在するアプリが必要
渡すもの単体 HTML 1枚（Meta）／ zip 1つ（TikTok）
表示サイズ縦向き（Meta は縦向き必須）
実測サイズ25.8〜36.1KB。Meta の上限 2MB に対して 1.3〜1.8%
遷移先ネットワークの API 経由でストアへ。任意の URL は指定できません
アプリをお持ちでない場合は使えません TikTok のプレイアブル広告はアプリのインストール獲得を目的とした枠に限定されており、Meta も同様です。 クリック時に呼ばれる API が URL を受け取らない仕組みのため、商品ページなど Web への誘導はできません。 その場合は「記事に埋め込む」か「ディスプレイ広告枠」をご検討ください。

普通のバナー枠に入る、遊べる HTML5 素材

300×250 などの一般的なディスプレイ広告枠に、そのまま入る形式です。 プレイアブル広告と違ってアプリ広告の枠に限定されず、 商品ページなど Web サイトへの誘導を目的とした配信に使えます。

帯サイズ（728×90 など）は対象外です 正方形のゲームが入らないためです。遊べないものを無理に押し込むより、 その枠は静止画のティザーにして誘導先へ送る形をお勧めします。
