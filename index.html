記事に差し込めるゲーム広告

記事の本文中に <iframe> タグ1個で差し込めるゲームです。 画像・スクリプト・音はすべて当方のサーバーから配信するため、御社側での開発・ファイル設置は不要です。 下のプレビューはその場で遊べます。

1ゲームを選ぶ

どれも表示は正方形（1:1）で統一してあります。 ゲームを差し替えても、貼るコードの形と枠の大きさは変わりません。

「埋め込みコード」ボタンについて 上のプレビューの右下に出ているボタンからも、同じコードをコピーできます。 このボタンはこのメニューと、ゲームを直接開いたときにだけ表示されます。 実際に記事へ埋め込むと自動的に隠れるので、読者には見えません。

2貼り方

コピーしたコードを、記事本文の掲載したい位置に貼り付けてください。形は次のとおりです （src のゲーム名の部分だけが入れ替わります）。

3共通仕様

表示サイズ正方形（1:1）。原寸 720×720px、最大幅 720px で縮小表示。全ゲーム共通
実装HTML / CSS / JavaScript（Canvas 2D）。外部ライブラリ・フレームワークなし
操作タップ / クリック。キーボード（Space・Enter）にも対応
音あり。ページを開いただけでは鳴りません（「はじめる」押下後のみ）
Cookie / 個人情報いずれも使用・取得していません
計測表示・接触・完了・CTA クリックを postMessage で親ページへ送信（受け取りは任意）
CTAゲーム終了後に「詳しくはこちら」を表示。新しいタブで開くため、記事のページは残ります

4SNS のフィードで遊べる版

同じゲームを、TikTok や Meta の縦型フィードの中でその場で遊べる プレイアブル広告の形式にしたものも用意しています。 記事に貼る iframe 版と違い、単体 HTML 1枚に画像・スクリプトまで内包し、 外部への通信を一切行わない形式です（各社の審査要件のため）。

プレイアブル広告の掲載イメージを見る

この枠はアプリ広告の枠です TikTok・Meta のプレイアブル広告はアプリのインストール獲得を目的とした枠で、 ストアに実在するアプリが必要になります。Web の LP へ誘導する案件では、 上の iframe 版をご検討ください。

5ディスプレイ広告枠で配信する版

同じゲームを、普通のディスプレイ広告枠（300×250 などのバナー枠）に入る HTML5 素材にしたものです。プレイアブル広告と違ってアプリ広告の枠に限定されず、 Web サイトへの誘導を目的とした配信に使えます。
