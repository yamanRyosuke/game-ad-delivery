記事内にゲーム広告を掲載するテスト

記事の本文中に、遊べるゲームを広告として1枠差し込むための手順です。 貼っていただくのは <iframe> タグ1個だけで、 画像・スクリプト・音はすべて当方のサーバーから配信されます。 御社側での開発・ファイル設置・ビルドは不要です。

1まず掲載イメージをご覧ください

実際に記事へ埋め込んだ状態の見本です。スマートフォンからも開いてみてください。 ページ下部には、ゲームから送られてくるイベントの受信ログも表示しています。

3掲載後の確認

PC とスマートフォンの両方で、記事ページを開いて確認してください。

  • 枠の中にゲームのタイトル画面と開始ボタンが表示される
  • 画面の左上に、青い枠にオレンジの × 印が入った四角が出ている （外部画像が読めているかの目印です。これが出ていなければご連絡ください）
  • 「自分で遊ぶ」を押すとゲームが始まる
  • 板の上をタップした位置に人が乗る
  • 広告の上を縦にスワイプしても、記事が普通にスクロールできる
  • 横スクロールが発生していない
  • ページを開いただけでは音が鳴らず、開始ボタンを押した後に鳴る
  • 終了後に出る「詳しくはこちら」を押すと、新しいタブで開き、記事のページはそのまま残る

4枠が表示されないとき

ブラウザの開発者ツール（F12）の Console に出るメッセージで、原因が切り分けられます。

Console に出るメッセージ原因と対応
Refused to frame '...' because it violates the following Content Security Policy directive: "frame-src ..." 御社サイトの CSP による拒否です。 配信ドメイン yamanryosuke.github.io を frame-src に追加していただく必要があります。 当方の設定では解決できません。
Mixed Content: ... was loaded over HTTPS, but requested an insecure resource URL が http:// になっています。https:// でお貼りください。
Refused to display '...' in a frame because it set 'X-Frame-Options' 当方の配信サーバー側の問題です。ご連絡ください。
何も出ないが枠が空白 広告ブロッカー、または sandbox 属性が付いている可能性があります。 下の「sandbox を付ける場合」をご覧ください。

sandbox 属性を付ける場合

御社の運用で sandbox が必須の場合、最低限この4つが必要です。

sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox"
値無いとどうなるか
allow-scriptsゲームが起動しません
allow-same-origin画像とスクリプトが読めません
allow-popups「詳しくはこちら」が開きません
allow-popups-to-escape-sandbox遷移先のページが正しく動きません

5計測をご希望の場合（任意）

ゲームは親ページへ postMessage でイベントを送っています。 受け取る実装は必須ではありません。受け取らなくても掲載には支障ありません。 御社の GA4 等で計測される場合は、以下を記事ページに追加してください。

イベントタイミング / 主なデータ
game_ready枠が表示され、ゲームの読み込みが完了した（＝インプレッション）
first_interaction読者が最初に操作した1回だけ（＝エンゲージメント）
game_startゲーム開始
game_complete終了。score / outcome / playTimeMs を含む
cta_click「詳しくはこちら」がクリックされた（＝送客）

受信側では必ず origin を確認してください message イベントは、他の iframe やブラウザ拡張からも届きます。 上のコードのように送信元を検証しないと、無関係なメッセージを計測してしまいます。

6技術仕様

表示サイズ正方形（1:1）。原寸 720×720px、最大幅720pxで縮小表示
実装HTML / CSS / JavaScript（Canvas 2D）。外部ライブラリ・フレームワークなし
通信すべて当方のサーバー（HTTPS）から。御社サーバーへの負荷はありません
Cookie使用していません
個人情報取得していません
音あり。ページを開いただけでは鳴りません（開始ボタン押下後のみ）
対応Chrome / Safari / Edge / Firefox の最新版。iOS・Android 対応
AMP未対応。AMP ページには <amp-iframe> が必要なため、別途ご相談ください

不具合・ご質問は担当までご連絡ください。 Console のエラーメッセージと、ご確認いただいた端末・ブラウザを添えていただけると助かります。
